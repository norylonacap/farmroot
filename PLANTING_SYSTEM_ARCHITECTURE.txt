┌─────────────────────────────────────────────────────────────────────────────┐
│                            TIME PROGRESSION FLOW                             │
└─────────────────────────────────────────────────────────────────────────────┘

DayManager._process(delta)
    │
    ├─> day_timer += delta
    │
    ├─> if day_timer >= seconds_per_day:
    │       │
    │       ├─> current_day += 1
    │       ├─> emit day_advanced signal
    │       │
    │       └─> _advance_all_plants()
    │               │
    │               └─> get_tree().get_nodes_in_group("plants")
    │                       │
    │                       └─> For each plant:
    │                               │
    │                               └─> plant.advance_day()
    │                                       │
    │                                       ├─> currentStageDays += 1
    │                                       │
    │                                       └─> if currentStageDays >= daysPerStage[stage]:
    │                                               │
    │                                               └─> _instantiate_stage(nextStage)
    │                                                       │
    │                                                       ├─> Load next stage model
    │                                                       └─> Play Tween animation
    └─> day_timer = 0

┌─────────────────────────────────────────────────────────────────────────────┐
│                         ANIMATION PIPELINE                                   │
└─────────────────────────────────────────────────────────────────────────────┘

Plant Stage Change:
    │
    ├─> _instantiate_stage(stageIndex)
    │       │
    │       ├─> Clear old model
    │       ├─> Load new stage scene
    │       └─> Call _animate_growth(stage_node)
    │               │
    │               ├─> stage_node.scale = Vector3(0.1, 0.1, 0.1)
    │               │
    │               └─> create_tween()
    │                       │
    │                       ├─> set_trans(TRANS_ELASTIC)
    │                       ├─> set_ease(EASE_OUT)
    │                       └─> tween_property(scale → Vector3.ONE, 0.5s)
    │
    └─> Result: Smooth pop-in growth animation


┌─────────────────────────────────────────────────────────────────────────────┐
│                       INVENTORY TRACKING SYSTEM                              │
└─────────────────────────────────────────────────────────────────────────────┘

Player Script Variables:
    │
    ├─> seeds_count: int = 10
    │       │
    │       ├─> Decreases when planting
    │       └─> Displayed in UI
    │
    └─> harvested_crops: Dictionary = {}
            │
            ├─> {"carrot": 5, "tomato": 3}
            └─> Displayed in UI

Flow:
    Plant Seed ──> seeds_count -= 1 ──> Update UI
    Harvest ──────> crops["carrot"] += 1 ──> Update UI
