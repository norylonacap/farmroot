Before running the game, complete these steps:

[ ] 1. Read QUICK_REFERENCE.md (2 minutes)
[ ] 2. Open main.tscn in Godot Editor
[ ] 3. Add Node → Rename to "DayManager"
[ ] 4. Attach script: game/scene/day_manager.gd
[ ] 5. Set seconds_per_day = 60 in Inspector
[ ] 6. Select ItemBar node
[ ] 7. Add carrot_seed.tres to itemBarInventory array
[ ] 8. (Optional) Add day counter UI with day_ui.gd
[ ] 9. Press F5 to test!

Quick Test:
[ ] Select hoe (1/2/3 keys)
[ ] Press Q on ground (till soil)
[ ] Select seed (1/2/3 keys)
[ ] Press Q on tilled soil (plant)
[ ] Wait 60 seconds (watch it grow)
